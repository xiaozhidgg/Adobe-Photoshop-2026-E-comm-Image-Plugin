# 电商图片制作 · Photoshop 2026 UXP 插件

一键把商品图做成电商主图：**去掉背景 → 换纯色背景 → 按主体自动调色 → 自动摆正 → 智能构图 → 批量导出多个尺寸**。

面向 Adobe Photoshop 2026（UXP 面板）。**不需要** Creative Cloud Desktop，也**不需要** UXP Developer Tool。

> **一键安装 / 卸载**：双击仓库根目录的 [`一键安装.bat`](一键安装.bat) / [`一键卸载.bat`](一键卸载.bat)。脚本会自己检查 Photoshop 是否已完全退出、自动找 PowerShell、给出中文结果；**不需要管理员权限**。命令行方式、排错、开发者模式说明见 [`安装说明.md`](安装说明.md)。

## 怎么用

面板从上到下三块：

| 区块 | 内容 |
|---|---|
| **一键全流程** | 按「抠图 → 边缘净化 → 应用蒙版（烘焙进像素）→ 自动摆正 → 背景 → 接地投影 → 调色 → 尺寸构图 → 导出」顺序跑完；失败步骤会给宿主原文错误并停下（烘焙失败只警告，不打断后续步骤）|
| **模块单跑** | 每个模块有独立按钮和开关：抠图 / 边缘净化 / 自动摆正 / 背景色 / 投影 / 调色 / 构图 / 导出。只处理你在 PS 里打开的那张文档 |
| **预设** | 尺寸、色板、调色默认值都能增删；`导入/导出 JSON` 可把整套预设备份或换机器 |

几个要点：

- **调色每一项都能单独关掉**。默认全部以**调整图层**落地（锐化/降噪用智能对象 + 智能滤镜），原始像素不动，做完还能在 PS 里继续改。
- **去背景结果保留为图层蒙版**，不满意可以直接拿画笔修，不用重跑；「应用蒙版」模块把蒙版**烘焙进像素**（等价 PS 的 图层 → 图层蒙版 → 应用），交付时图层更干净。
- **边缘净化**：蒙版收缩 + 羽化，专治抠完留一圈白边。
- **一键回退**：处理前会打快照，不满意一键回到处理前。
- **导出**：`<原名>_<宽>x<高>.<格式>`，默认输出到**原图同目录**的 `output\` 子文件夹；面板里也能**自选输出目录**（留空＝原图同目录）。
- **尺寸**：内置 800×800 / 1254×1254 / 1600×1600，可多选，可自定义增删。选中的最大尺寸作为**基准画布**，先在大画布上把构图规范化，再等比缩放导出各档 —— 所以各尺寸的留白比例天然一致。

### 自动摆正（支持多物体）

把拍歪的主体调正：先量出主体的倾斜角，再绕图层中心旋转回去，**旋转后回读复核**；没转到位会自动反向补一次，转完自动取消选区。

- **一个物体**：按它的倾斜角旋转。
- **多个物体**（例如一支牙膏 + 一个纸盒同框）：先按连通域把物体分开，分别量出各自的倾斜角，再用矩形选区限定范围**逐个物体各转各的角度**，互不干扰。
- 抠图后旋转前会先把**图层蒙版烘焙进像素**（否则转出来的边角会被旧蒙版按原轮廓裁掉）。
- 两个物体挨得太近、转一个会带动另一个时，会跳过并写明原因；倾斜超过阈值（默认 5°，可调）时只给结论不自动动画面 —— 自动摆正只做小角度微调。

## 已知局限

1. **去背景走的是 Adobe 自家 `autoCutout` 的等价描述符链**（逐字对齐官方面板源码），功能与「原版去背景」一致，但实现路径不是那颗按钮本身 —— `removeBackground` 在 Action Manager 里不是可调用事件。
2. **非正方形尺寸会把主体拉变形**。基准画布是正方形，构图规范化后**拉伸**到目标尺寸。内置的三档都是正方形，不影响；自己加 1000×1500 这类尺寸才会触发。需要的话可以补「居中裁切 / 补边」而不是拉伸。
3. 去背景质量取决于 PS 自身的 AI 模型；本插件不自带分割模型。
4. 锐化/降噪的「自动值」是启发式估算，不保证优于手动。
5. 自动摆正只处理「整张图里所有物体都朝同一方向、且倾斜小于阈值」的常规情况；**透视倾斜**（相机斜着拍导致的梯形变形）不做矫正。
6. 刻意**没做**：取主体主色自动生成背景。

## 安装 / 卸载

**一键（推荐）**：双击 `一键安装.bat`；要卸载就双击 `一键卸载.bat`（会先等你退出 Photoshop，卸载后还能选择是否一并清掉面板设置与日志）。

**命令行**（想看清每一步时）：

```powershell
# 干跑：只报告要做什么，不写文件
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -DryRun

# 安装
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1

# 卸载
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall
```

两个 bat 也支持干跑：`一键安装.bat dry`、`一键卸载.bat dry`。

安装位置：`%APPDATA%\Adobe\UXP\Plugins\External\com.ecom.psimage\`；卸载时该目录被改名为 `com.ecom.psimage.bak-<日期时间>`（**保留备份，不直接删除**）。卸载**不会**关闭开发者模式；要关请在 PS 里：**编辑 → 首选项 → 增效工具** → 取消勾选「启用开发人员模式」。

## 更新到新版本

**不用先卸载**，覆盖安装即可：

1. **完全退出 Photoshop**（安装脚本会自己检查，没退出会拒绝写入）。
2. 从 [Releases](https://github.com/xiaozhidgg/Adobe-Photoshop-2026-E-comm-Image-Plugin/releases) 下载新版本 zip，解压后**双击 `一键安装.bat`**（等价于命令行再跑一次 `install.ps1`）。
3. 重启 Photoshop，面板里就是新版本。

- 安装脚本**幂等**：覆盖前会把你当前的插件目录改名备份为 `com.ecom.psimage.bak-<日期时间>`，想回退就把备份目录名改回 `com.ecom.psimage`（先退出 PS）。
- **预设、面板设置、日志不会被清**（它们存在 `%APPDATA%\Adobe\UXP\PluginsStorage\...` 里，安装只替换插件本体）。
- 确认当前版本：看 Release 页面的标签，或 `plugin\manifest.json` 里的 `version`。
